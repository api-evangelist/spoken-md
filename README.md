Spoken.md provides a Podcast Transcript API that returns clean, speaker‑labeled Markdown transcripts for any podcast episode. The service indexes over 26,000 transcripts and offers a free demo key for a single episode. Users can search episodes by text or URL, retrieve full transcripts, and integrate the data into knowledge bases, LLM prompts, or searchable archives. Credits are charged per transcript, with packs and top‑up options, and credits never expire. The API is designed for AI agents and developers building searchable podcast archives.
